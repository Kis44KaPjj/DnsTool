***Interactive CLI tool for DNS diagnostics (A/AAAA, PTR, NS) written in Go.***

## Installation Guide
1. git clone https://github.com/Kis44KaPjj/DnsTool.git
2. cd DnsTool
3. go build -ldflags="-X main.version=0.2.2" -o dnstool

## Binaries Guide
1. 1. wget https://github.com/Kis44KaPjj/DnsTool/releases/download/v0.2.2/dnstool
2. 2. chmod +x dnstool
   3. cp dnstool /usr/local/bin/dnstool
